# AccessHub Reseller Demo Builds

Public build sources for the AccessHub fictional demonstration apps. Every native shell permanently displays **DEMO — NOT VALID ID** and restricts embedded navigation to the fictional demo routes.

This repository contains sanitized application sources and automated build instructions. It contains no licensing service, customer records, private credentials, signing keys, or earlier private repository history.

The iOS archive is built without a distribution signing identity for installation through an authorized signing workflow. Build artifacts are attached to successful GitHub Actions runs.

The included MIT license and original copyright notice are retained. Desktop components originate from the MIT-licensed IPALOADER project by nab138; the fictional demo wrappers and route restrictions are AccessHub modifications.
